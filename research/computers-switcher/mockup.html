10. Compact sidebarThe switcher is the first pill: the selected computer's icon with its status dot and the "waiting elsewhere" badge. Click opens the same menu. Only one Bots pill (the selected computer's) instead of one per computer.

Behaviour in short

  • Shown only when two or more computers are known (saved or connected). With one, nothing changes.
  • Default This Mac. The choice is remembered per device. If the saved computer is removed, the switcher falls back to This Mac.
  • Filters Projects, Bots, Threads (all shelves) and sidebar Search. "No project" means the selected computer's scratch project. The Tasks and Agents pages keep their own all-computers view.
  • New thread starts on the selected computer. In All computers it keeps today's rule (the current thread's computer, else This Mac).
  • Opening a thread from another computer (link, palette, notification) switches the sidebar to that computer, the same way a hidden project scope widens today.
  • Keyboard: Ctrl+1 for This Mac, Ctrl+2 and on for the others, Ctrl+0 for All computers (open question).
